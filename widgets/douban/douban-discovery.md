# 豆瓣全景

`douban-discovery.js` 是单文件 Forward / REX 模块，版本 `1.2.1`，要求模块接口 `>= 0.0.2`。

## 分类入口

| 模块 | 主分类 | 子分类 |
| --- | --- | --- |
| 豆瓣一周口碑 | 五个独立榜单 | 一周口碑电影、华语口碑剧集、全球口碑剧集、国内口碑综艺、全球口碑综艺 |
| 豆瓣电影 | 全部、近期热门、高分经典、冷门佳作、地区佳作、分类题材、年度榜单 | 26 个题材，12 个近期热门、26 个高分经典、19 个冷门佳作、184 个地区题材榜；2014–2025 年 108 个年度榜；保留 Top 250、热门/最新筛选、院线与实时榜 |
| 豆瓣电视 | 全部、高分经典、近期热门、冷门佳作、分类题材、年度榜单 | 原生近期热门 5 榜、高分经典 9 榜、冷门佳作 9 榜、地区题材 33 榜；2014–2025 年 82 个年度榜；保留动画、纪录片和综艺筛选 |
| 豆瓣实时热门 | 书影音、电影榜、电视榜 | 书影音保留原条目类型，图书与音乐只提供信息详情 |

子分类通过 `belongTo` 跟随主分类显示。固定榜单保留源站顺序。电影和电视的“全部”支持综合、近期热度、首映/首播时间、高分优先四种排序。

电影、电视及年度榜均直接读取第一方 `category_tabs` 对应的 collection，不再用评分、人数或自由筛选代替原生榜。题材入口按 26 个题材提供其高分经典；近期热门、冷门佳作和地区榜分别提供该题材下实际存在的子榜。原生空榜保留为空。目录是 2026-10-18 的快照，之后豆瓣新增年份或榜单需要更新快照，见 [完整接口审计](../../docs/douban-interface-audit-2026-10-18.md)。

“豆瓣偏好探索”按电影和电视显示不同题材、地区；电视题材把电视剧/综艺形式与类型绑定，防止错误组合。1960–1990 年代输入自动转换为 `60年代`–`90年代`，2000 年代起保留四位年号。广告、片单推广及缺少 ID/标题的条目不会生成影片卡片。未知显式类型和嵌套广告会跳过；仅对来源明确的电影/电视列表补足缺失类型。新枚举字段在请求前校验，旧自由标签仍可用。

## 原有功能和兼容

自定义 Doulist / collection、分类推荐、偏好探索、我看、Cookie 个性推荐和影人作品继续保留。`doubanPublic` 改名为“一周口碑”，但仍接受旧配置中的全部 collection 值，包括旧 Top 250、剧集分类和首页精选。旧模块 ID、函数名以及已保存的旧参数继续可读；新界面使用按媒体分类的筛选字段，默认“沿用已有筛选”；显式选择“全部”会清空对应旧条件。旧电影地区与题材配置保留原筛选语义，重新选择原生榜可获得与豆瓣榜单一致的内容。

“豆瓣我看”支持想看、在看、看过，以及最多扫描 5 页后抽取 9 项的随机想看。影人入口支持 ID、豆瓣 URL，或上游 suggestion 可用时的唯一精确姓名。

## 影视匹配与详情

- 优先使用标题、媒体类型、年份和唯一性证据进行 TMDB 匹配，不按热度或搜索第一项选片。
- 首轮未匹配时，补取豆瓣详情中的原名、别名和年份，再尝试有限的候选搜索。
- 对“第二季 / Season 2”等季度条目，仅当 TMDB 主剧中存在相应季号且该季年份符合时才接受。输出保留数值 TMDB 剧集 ID，并使用 REX 支持的 `season` 整数字段区分季度；日期来自匹配到的该季，不使用整部剧首播日期。电影续集不当作季号删除。
- 去重包含季号，同剧不同季可同时保留。季度匹配缓存已换为新版本，旧的整剧日期缓存不再读取。
- 安全匹配失败时，条目仍有可读的豆瓣简介、海报等详情，不把另一部同名作品当作正确结果。
- 图书、音乐不会送入 TMDB 影视搜索。
- TMDB 请求全局最多 4 并发，候选查询按原顺序合并；内存详情缓存最多 128 项。公开身份缓存带过期时间，个人列表不缓存个人内容。

## 隐私

脚本不内置 TMDB key，使用宿主 `Widget.tmdb`。个性化 Cookie 只发送到 `https://m.douban.com`，禁用自动重定向，不写日志、存储，也不发送给 TMDB。自定义片单只接受豆瓣 HTTPS URL，提取 ID 后构造固定 API 地址。

## 验证

```bash
npm run test:douban
node --test tests/douban-details.test.js
npm run test:douban:live
npm test
npm run check
```

回归测试使用不提供 Node timer、`fetch`、`require` 或 `process` 的 VM。在线检查不使用 Cookie。`node audit-douban-interfaces.cjs /tmp/douban-interface-results.json` 覆盖所有当前公开入口枚举、旧接口、代表分页、片单、影人和书影音详情，并单独记录空榜和错误。在线 API 成功不等同于 REX 界面内的播放或视觉验收。

豆瓣 `rexxar`、`j/search_subjects` 和 suggestion 是 Web 接口，字段与风控可能变化。源级 401、403、429、坏 JSON、缺少必需列表字段或非数组字段明确报错；真实空数组保留为空榜。影人姓名搜索无法获得唯一精确结果时应使用 ID / URL。
