# 豆瓣全景

`douban-discovery.js` 是单文件 Forward / REX 模块，版本 `1.1.0`，要求模块接口 `>= 0.0.2`。

## 分类入口

| 模块 | 主分类 | 子分类 |
| --- | --- | --- |
| 豆瓣一周口碑 | 五个独立榜单 | 一周口碑电影、华语口碑剧集、全球口碑剧集、国内口碑综艺、全球口碑综艺 |
| 豆瓣电影 | 全部、近期热门、高分经典、冷门佳作、地区佳作、分类题材 | 热门/最新各 5 个地区，院线热映与实时榜；Top 250 与分地区高分；23 个地区选项；21 个题材 |
| 豆瓣电视 | 全部、近期热门、冷门佳作、分类题材 | 大陆剧、美剧/欧美剧、日剧、韩剧、动画、纪录片、国内外综艺；地区筛选；电视剧 21 个题材及综艺 4 个题材 |
| 豆瓣实时热门 | 书影音、电影榜、电视榜 | 书影音保留原条目类型，图书与音乐只提供信息详情 |

子分类通过 `belongTo` 跟随主分类显示。只有当前分类的参数参与请求，切换分类后残留的隐藏参数不影响查询。固定榜单保留源站顺序，全部/地区/题材支持综合、近期热度、首映或首播时间、高分优先四种排序。

电视没有原生冷门榜。本模块的“冷门佳作”是透明筛选：每页从豆瓣推荐取 100 项，保留评分 ≥ 8 且评价人数 1–10000 的条目；电影“地区佳作”使用评分 ≥ 8 的地区筛选。详见 [API 核查记录](../../docs/douban-api-2026-10-18.md)。

## 原有功能和兼容

自定义 Doulist / collection、分类推荐、偏好探索、我看、Cookie 个性推荐和影人作品继续保留。`doubanPublic` 改名为“一周口碑”，但仍接受旧配置中的全部 collection 值，包括旧 Top 250、剧集分类和首页精选。其余旧模块 ID、函数名与参数不变。

“豆瓣我看”支持想看、在看、看过，以及最多扫描 5 页后抽取 9 项的随机想看。影人入口支持 ID、豆瓣 URL，或上游 suggestion 可用时的唯一精确姓名。

## 影视匹配与详情

- 优先使用标题、媒体类型、年份和唯一性证据进行 TMDB 匹配，不按热度或搜索第一项选片。
- 首轮未匹配时，补取豆瓣详情中的原名、别名和年份，再尝试有限的候选搜索。
- 对“第二季 / Season 2”等季度条目，仅当 TMDB 主剧中存在相应季号且该季年份符合时才接受，不将电影续集当作季号删除。
- 安全匹配失败时，条目仍有可读的豆瓣简介、海报等详情，不把另一部同名作品当作正确结果。
- 图书、音乐不会送入 TMDB 影视搜索。
- TMDB 请求全局最多 4 并发，候选查询按原顺序合并；内存详情缓存最多 128 项。公开身份缓存带过期时间，个人列表不缓存个人内容。

## 隐私

脚本不内置 TMDB key，使用宿主 `Widget.tmdb`。个性化 Cookie 只发送到 `https://m.douban.com`，禁用自动重定向，不写日志、存储，也不发送给 TMDB。自定义片单只接受豆瓣 HTTPS URL，提取 ID 后构造固定 API 地址。

## 验证

```bash
npm run test:douban
node --test tests/douban-details.test.js
npm run test:douban:live
npm test
npm run check
```

回归测试使用不提供 Node timer、`fetch`、`require` 或 `process` 的 VM。在线检查不使用 Cookie，覆盖五个口碑榜、电影六类、电视四类、三个实时榜及原有片单功能。在线 API 成功不等同于 REX 界面内的播放或视觉验收。

豆瓣 `rexxar`、`j/search_subjects` 和 suggestion 是 Web 接口，字段与风控可能变化。源级 401、403、429 或坏 JSON 明确报错。影人姓名搜索无法获得唯一精确结果时应使用 ID / URL。
